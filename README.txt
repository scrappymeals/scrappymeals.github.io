DAMON VERSAGGI — HOLOGRAPHIC PORTFOLIO

Extract the entire ZIP, then open index.html. Keep the assets folder alongside index.html.

Use the play controls or project menu to navigate. Next loops back to the overview. Tap a project image to enlarge it; tap again to close. Sounds start after interaction.

For a public mobile-friendly URL, upload index.html and assets together to a static website host. Google Fonts and external project links require internet access. Images and the embedded CV are included locally.

Validation: all slides at widths 320, 390, 768, 820, 1024 and 1440; simulated touch image controls; desktop/tablet panel fitting; navigation and CV download. Physical iOS/Android testing was not performed.
